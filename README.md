# +60 Oportunidades para Redução da Carga Tributária

Site estático com oportunidades tributárias para economia e recuperação de créditos.

## Conteúdo

- +60 oportunidades tributárias
- Cards expansíveis com teses, oportunidade e plano de ação
- Busca e filtros por tributo (PIS/COFINS, ICMS, IRPJ/CSLL, Previdenciário, IPI, IBS/CBS etc.)
- Layout responsivo

## Proteção

- Menu de contexto (botão direito) desabilitado
- Atalhos de código-fonte (Ctrl+U, Ctrl+S, F12, DevTools) bloqueados
- Texto **visível** nos cards permanece selecionável e copiável

## Publicar no GitHub Pages

```bash
git init
git add .
git commit -m "Site +60 Oportunidades"
git branch -M main
git remote add origin https://github.com/silvioalbqrq/60-Oportunidades.git
git push -u origin main
```

Em **Settings → Pages**, escolha a branch `main` e a pasta `/ (root)`.
